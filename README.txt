ELARA — QR code set (Route A: one code → link hub page)
========================================================
The code opens https://elara-h-salon.github.io/ — Elara's link hub page, which lists WhatsApp (pre-filled booking message),
Instagram, TikTok and Snapchat. Update the page any time — the printed code never changes.

FILES
  elara-qr-gold-on-cream.svg / .png   Branded: deep-gold modules, Elara mirror mark in the centre (preferred)
  elara-qr-navy-on-cream.svg / .png   Branded: midnight-navy modules, same mark — highest contrast
  elara-qr-plain-black.svg / .png     Plain black on white, no logo — fallback for very small print or low-quality printing
  elara-qr-print-card.png             Ready-to-print 1080x1350 card: logo, code, "Scan to book" in English and Arabic

PRINT RULES
  - SVG files scale to any size without loss; PNGs are 2000 px.
  - Minimum printed size: 2.5 cm wide for hand-held scanning, 10 cm+ for the van or a shop window.
  - Keep the cream margin around the code (quiet zone); don't crop into it.
  - Always print on a light background; never invert to light-on-dark.
  - All files were test-scanned at 2000, 500, 200 and 120 px.
